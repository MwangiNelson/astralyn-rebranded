## The one-paragraph version

Astralyn sells engineering time, which does not compound. The suite converts
what the studio already knows about how local operators run into software that
earns while nobody is working on it. Five products — vehicles, buildings,
money, customers, crews — all standing on one platform (**Astralyn Core**) so
that a four-founder team can plausibly run five products instead of building
five auth systems.

**Relay is first because it already exists** as a working fleet system in our
own repos. **Aegis is built first** because nothing else can be multi-tenant
until it is.

---

## How to read the statuses

They are honest, and they stay honest — on the site as well as here.

- **Live** — in production, being used, sellable now
- **In Build** — actively under development, has a committed scope
- **Concept** — specified, not started, may never be built

Nothing is promised to a customer on the strength of a concept PRD.
